## Overview

markdownr is a Wails v2 desktop app: Go backend at the repo root, React 19 + TypeScript + Vite frontend in `frontend/`. Still close to the Wails template (recently migrated from Svelte to React).

## Commands

Run from repo root:
- `wails dev` — live development (Vite HMR; browser dev server with Go bindings at http://localhost:34115)
- `wails build` — production package (output in `build/bin/`)

Run from `frontend/` (Node version in `frontend/.node-version`):
- `npm run check` — typecheck (`tsc --noEmit`)
- `npm run lint` — `oxfmt --check && oxlint`
- `npm run format` — `oxfmt && oxlint --fix`

No test framework is configured yet. ESLint and Prettier were removed in favor of oxlint/oxfmt (config: `frontend/.oxfmtrc.json` — single quotes, JSX single quotes, sorted imports). A husky pre-commit hook runs `lint-staged` (oxfmt on staged files).

## Architecture

- `main.go` embeds `frontend/dist` (`//go:embed all:frontend/dist`) and starts Wails, binding the `App` struct. The frontend must be built before `go build` alone will work; `wails build`/`wails dev` handle this via `wails.json` (`frontend:build`, `frontend:dev:watcher`).
- `app.go` defines `App`. Its exported methods are exposed to the frontend as JS bindings.
- `frontend/wailsjs/` is generated by Wails (gitignored) — do not edit. `wailsjs/go/main/App.js` holds the Go method bindings (e.g. `Greet`), `wailsjs/runtime/` the Wails runtime API. Bindings regenerate on `wails dev`/`wails build` after adding or changing Go methods on `App`.
- Frontend entry: `frontend/src/main.tsx` mounts `App.tsx` into `#app` in `frontend/index.html`.
